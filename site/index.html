PLUS 功能一覽

保留新酷音的準確，加上超順手的現代效率工具

所有 Plus 功能皆建構在公開的 libchewing C API 之上，不破壞原本注音習慣，並可逐項開關。

全平台預設開啟

免打聲調

不必逐字敲聲調鍵——輸入下一個字的聲母時，前一個字會自動選好。照原本習慣打聲調也完全相容。

ㄋㄧㄏㄠㄇㄚ + Space → 你好嗎
全平台預設開啟

邊打邊列字

每敲一個注音符號，下方立刻列出最可能的常用字，用 Shift+1…9 直接選取，不必等整個音節打完。

ㄋ年　您　你　能　內…
ㄋㄧ你　妳　泥　擬…

詞語建議與字首注音

雙向加速長詞輸入：打前兩個字自動補全後文，或只敲每個字的第一個注音直接展開整句，用 Shift+1…9 選取，不干擾原本按鍵。觸發門檻可自訂（預設 2 個聲母）。

中華 → 中華民國 / 中華隊
ㄍㄒㄈㄘ → 恭喜發財
ㄇㄇ → 密碼 / 買賣 / 媽媽

內嵌英文模式與智慧提示

免切輸入法就能在中文句子裡插入英文並自動修正大小寫，前後中文留在組字區內持續可編輯。忘記切模式直接打英文時，下方自動提示轉換，按一下快速鍵直接填入。

Ctrl+Shift+Space 或 右 Shift ×2 → [EN] github → GitHub
Ctrl+Shift+Space → GitHub 直接把英文當注音打也會自動偵測

Emoji 候選與 1,900+ 短碼

打「開心」按 ↓ 直接帶出「開心😊」；連按兩下 ; 就能用 GitHub / Slack 風格短碼搜尋超過 1,900 個表情符號，並支援自訂詞表。

;;smile😄 :smile
;;fire🔥 :fire
開心 ↓開心😊

即時計算機

組字區為空時按 = 直接輸入四則算式，按 Enter 輸出結果。支援 + - * / % ( ) 與小數。

=1+2*3 → 7

中英數自動空格

中文與英文字母、數字相接時自動補上盤古空白，英文字母與數字可獨立開關，排版乾淨不費力。

本機語音輸入（voxkit）

按住快速鍵說話、放開即出字（Linux 預設右 Alt，macOS 預設右 Option）。由內附的 voxkit 服務在本機以 Qwen3-ASR-0.6B + Silero VAD + OpenCC s2twp 辨識並轉成台灣繁體，錄音絕不上傳，且會自動帶入你的新酷音個人詞庫提高專有名詞準確率。

🔒 音訊不離開本機 🇹🇼 OpenCC 台灣用語轉換 📚 自動參考個人詞庫 💤 預設不啟用，零閒置佔用

密碼欄位防護與中／英切換

偵測到密碼或敏感欄位時，自動停用所有 Plus 面板、自動空格與語音輸入。IBus 與 macOS 內建單按左 Shift 切換中／英並於狀態列顯示指示。

左 Shift ⇄ 中 / 英

每個平台，只要一個安裝檔

所有安裝檔均附帶 libchewing 0.14、輸入法、預編譯詞庫與選用的 voxkit 語音服務。

macOS

Apple Silicon · macOS 13+
.pkg

安裝後自動註冊「新酷音 Plus」。所有 Plus 功能預設開啟，語音輸入可在安裝程式「自訂」畫面或輸入法選單中啟用。

套件未經 Apple 簽章：請對 .pkg 按右鍵 →「打開」以通過 Gatekeeper。
下載 macOS 安裝檔

Arch Linux · fcitx5

x86_64 · All-in-one
.pkg.tar.zst

取代系統的 libchewing（0.13）與 fcitx5-chewing。免打聲調與邊打邊列字預設開啟，其餘 Plus 選項可在 fcitx5 設定中啟用。

sudo pacman -U chewing-plus-fcitx5-*.pkg.tar.zst
前往 GitHub Releases

Arch Linux · IBus

x86_64 · GTK4 / libadwaita
.pkg.tar.zst

含原生 IBus 引擎與「新酷音 Plus」設定程式（可管理 Plus 開關與語音模型）。安裝後執行 ibus restart 並加入輸入法即可。

sudo pacman -U chewing-plus-ibus-*.pkg.tar.zst && ibus restart
前往 GitHub Releases
預設行為與自訂詞庫

免打聲調與邊打邊列字在三個平台皆預設開啟；語音輸入預設不啟用（載入模型約佔 260 MB RAM，首次使用前於設定中下載 ~850 MB 模型）。fcitx5 亦支援在 ~/.local/share/fcitx5-chewing/ 放置自訂的 plus-emoji-shortcodes.txt 與 plus-english.txt。
